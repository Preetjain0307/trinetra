# TRINETRA Frontend (React 19 + Vite + TailwindCSS)

Tactical Border Defense Situational Awareness & Multi-Camera Matrix Interface.

## 🌟 Modules & Views
- **Command Center (`/`)**: Real-time common operational picture (COP), KPI widgets, shift briefings, and active incident response desk.
- **Surveillance Matrix (`/surveillance`)**: 20-node synchronized border video feeds with live moving detection reticles, PTZ gimbal controls, and night mode.
- **Border Digital Twin (`/border-twin`)**: Interactive 3D/Leaflet geospatial map with live sensor ranges, camera frustums, and zone geofences.
- **Incident Center (`/incidents`)**: Multi-sensor correlated incident desk with XAI reasoning, contributing sources breakdown, and status workflows.
- **Investigation Desk (`/investigation`)**: Historical timeline player, sensor correlation graphs, and SHA-256 evidence chain verification.
- **Demo Scenarios (`/demo-scenarios`)**: Step-by-step interactive runner for 4 tactical border demonstration scenarios.
- **Sensors, Personnel & Vehicles (`/sensors`, `/personnel`, `/vehicles`)**: Real-time registry and telemetry inspector.
